# cqagc/tap

Homebrew tap for [CQAGC open-source tools](https://www.cqagc.com/en/open-source) by Chongqing HongChuangDa Technology.

```sh
brew install --cask cqagc/tap/mulee
```

| Cask | Description | Website |
|---|---|---|
| [mulee](https://github.com/cqagc/mulee) | Downloader for HTTP, BitTorrent, eD2k and video sites (macOS 26+, Apple silicon) | [cqagc.com/en/mulee](https://www.cqagc.com/en/mulee) |
